# Git: VS Code vs терминал

## Удобно в VS Code
1. Diff прямо в редакторе: клик по файлу в Source Control — изменения видны построчно, бок о бок.
2. Частичный stage: можно добавить в индекс отдельные строки/блоки, а не весь файл.
3. Встроенный редактор merge-конфликтов с кнопками Accept Current / Incoming / Both и GitLens с blame по каждой строке.

## Удобнее в терминале
1. `git rebase -i`, `git reflog`, `git cherry-pick` — полный контроль и видно, что именно происходит; в UI эти операции спрятаны или отсутствуют. Плюс на сервере по SSH будет только терминал.
