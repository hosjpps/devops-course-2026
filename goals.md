# Цели на семестр

1. Собрать для своего пет-проекта Docker-образ и поднимать его одной командой `docker compose up`.
2. Настроить CI/CD на GitHub Actions: линтер и тесты на каждый PR, автодеплой из `main`.
3. Развернуть приложение на облачной VM (Ubuntu Server) с доступом по SSH-ключу и без пароля.
